# freeCodeCamp-Machine-Learning-with-Python-Projects

- The attached files in this repository contains a collection of projects I completed throughout the course of tthe FCC Machine Learning with Python course.
- Projects included concepts of Computer Vision, Convolutional Neural Networks (CNN), Natural Language Processing (NLP) and K Nearest Neighbours using mainly Tensorflow and Keras.
- Additional libraries used for visualisation of data include Matplotlib, Seaborn, Numpy and Pandas.
